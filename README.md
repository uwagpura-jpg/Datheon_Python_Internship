# Datheon Python Programming Internship

This repository contains three Python projects completed as part of the Datheon Python Programming Internship.

## Projects

### Task 1: Hangman Game
A command-line word guessing game built using Python.

**Features**
- Random word selection
- Tracks guessed letters
- Limits incorrect attempts
- Displays win or lose messages
- Handles repeated and invalid guesses

**Run the project**
```bash
python3 hangman.py
```

### Task 2: Automated File Organizer
A Python utility that organizes files into folders according to their file extensions.

**Features**
- Categorizes documents, images, videos, archives, and code files
- Creates category folders automatically
- Handles duplicate filenames without overwriting existing files
- Displays a summary of moved and skipped files

**Run the project**

Navigate to the Task 2 folder:
```bash
cd Task2_File_Organizer
python3 organizer.py
```

The program organizes files inside the `test_files` directory. Create this directory and place test files in it before running the program.

### Task 3: Rule-Based Terminal Chatbot
An interactive terminal chatbot that responds to predefined messages.

**Features**
- Responds to greetings and common questions
- Provides FAQ responses
- Displays the current date and India Standard Time
- Handles unknown messages
- Supports exit commands

**Run the project**

Navigate to the Task 3 folder:
```bash
cd ../Task3_Chatbot
python3 chatbot.py
```
